🎯 APA ITU MVC?
================================================================================

MVC adalah pola arsitektur software yang memisahkan aplikasi menjadi 3 komponen:

┌─────────────┬──────────────────────────────────────────────────────────────┐
│ MODEL (M)   │ Mengelola data dan berinteraksi dengan database             │
│             │ Lokasi: app/Models/                                          │
│             │ Contoh: Mahasiswa.php, Penguji.php, Osce.php                │
│             │ Jumlah: 18 models                                            │
├─────────────┼──────────────────────────────────────────────────────────────┤
│ VIEW (V)    │ Menampilkan user interface (UI) kepada pengguna             │
│             │ Lokasi: resources/js/pages/ dan resources/views/            │
│             │ Contoh: MahasiswaPage.jsx, PengujiDashboard.jsx             │
│             │ Jumlah: 41 React components + 4 Blade templates             │
├─────────────┼──────────────────────────────────────────────────────────────┤
│ CONTROLLER  │ Menghubungkan Model dan View, menangani HTTP request        │
│    (C)      │ Lokasi: app/Http/Controllers/                               │
│             │ Contoh: MahasiswaController.php, OsceController.php         │
│             │ Jumlah: 30+ controllers                                      │
└─────────────┴──────────────────────────────────────────────────────────────┘

🔄 ALUR REQUEST-RESPONSE (FLOW MVC)
================================================================================

Contoh: Admin membuka halaman daftar mahasiswa

1. USER memasukkan URL di browser
   ↓
   http://localhost/admin/mahasiswa

2. ROUTE (routes/web.php) mencocokkan URL dengan controller
   ↓
   Route::get('/admin/mahasiswa', [MahasiswaController@index])

3. MIDDLEWARE memeriksa autentikasi dan role
   ↓
   ['auth', 'role:admin'] ✅ User adalah admin yang sudah login

4. CONTROLLER menerima request
   ↓
   MahasiswaController@index()

5. CONTROLLER memanggil SERVICE untuk logika bisnis
   ↓
   MahasiswaService@getAll($search, $angkatan)

6. SERVICE memanggil MODEL untuk query database
   ↓
   Mahasiswa::query()->with('enrollment')->get()

7. MODEL mengeksekusi SQL query
   ↓
   SELECT * FROM mahasiswa LEFT JOIN enrollment...

8. DATABASE mengembalikan data
   ↓
   [{"id": 1, "nim": "12345", "nama": "John"}, ...]

9. Data kembali ke MODEL → SERVICE → CONTROLLER
   ↓

10. CONTROLLER mengirim data ke VIEW dengan Inertia
    ↓
    Inertia::render('Admin/MahasiswaPage', ['mahasiswa' => $data])

11. INERTIA mengkonversi data ke React props
    ↓

12. VIEW (React Component) me-render HTML
    ↓
    const { mahasiswa } = usePage().props;
    return <table>...</table>

13. USER melihat halaman daftar mahasiswa
    ↓
    Tampilan tabel mahasiswa di browser

// File: app/Http/Controllers/Admin/MahasiswaController.php

class MahasiswaController extends Controller
{
    protected $service;
    
    // Dependency Injection: Service di-inject otomatis
    public function __construct(MahasiswaService $service)
    {
        $this->service = $service;
    }
    
    // READ: Menampilkan daftar mahasiswa
    public function index(Request $request)
    {
        $search = $request->input('search');
        $angkatan = $request->input('angkatan');
        
        // Panggil service untuk ambil data
        $mahasiswa = $this->service->getAll($search, $angkatan);
        
        // Kirim data ke view dengan Inertia
        return Inertia::render('Admin/MahasiswaPage', [
            'mahasiswa' => $mahasiswa,
        ]);
    }
    
    // CREATE: Menyimpan mahasiswa baru
    public function store(Request $request)
    {
        // Validasi input
        $validated = $request->validate([
            'nim'   => 'required|unique:mahasiswa,nim',
            'nama'  => 'required|string|max:255',
            'kelas' => 'required|string',
            'prodi' => 'required|string',
        ]);
        
        // Panggil service untuk simpan
        $this->service->store($validated);
        
        // Redirect dengan pesan sukses
        return redirect()->route('admin.mahasiswa.index')
            ->with('success', 'Mahasiswa berhasil ditambahkan');
    }
    
    // UPDATE: Mengupdate data mahasiswa
    public function update(Request $request, Mahasiswa $mahasiswa)
    {
        $validated = $request->validate([...]);
        $this->service->update($validated, $mahasiswa);
        
        return redirect()->route('admin.mahasiswa.index')
            ->with('success', 'Data mahasiswa berhasil diupdate');
    }
    
    // DELETE: Menghapus mahasiswa
    public function destroy(Mahasiswa $mahasiswa)
    {
        $this->service->delete($mahasiswa);
        
        return redirect()->back()
            ->with('success', 'Mahasiswa berhasil dihapus');
    }
}

// File: app/Models/Mahasiswa.php

class Mahasiswa extends Model
{
    use HasFactory;
    
    // Nama tabel di database
    protected $table = 'mahasiswa';
    
    // Primary key
    protected $primaryKey = 'id_mahasiswa';
    
    // Kolom yang boleh diisi
    protected $fillable = [
        'id_pengguna',
        'nama',
        'nim',
        'kelas',
        'prodi',
        'status',
    ];
    
    // RELASI KE MODEL LAIN
    
    // Many-to-One: Satu mahasiswa punya satu pengguna
    public function pengguna()
    {
        return $this->belongsTo(Pengguna::class, 'id_pengguna');
    }
    
    // One-to-Many: Satu mahasiswa punya banyak enrollment
    public function enrollment()
    {
        return $this->hasMany(Enrollment::class, 'id_mahasiswa');
    }
    
    // One-to-Many: Satu mahasiswa punya banyak enrollment OSCE
    public function enrollment_osce()
    {
        return $this->hasMany(EnrollmentOsce::class, 'id_mahasiswa');
    }
}

================================================================================
⚙️ LAYER TAMBAHAN (SELAIN MVC)
================================================================================

1. SERVICE LAYER (app/Services/)
   Fungsi: Berisi logika bisnis aplikasi
   Contoh: MahasiswaService.php, OsceService.php
   
   Kenapa perlu? Agar Controller tetap "thin" (ringan) dan fokus pada
   handling request. Logika kompleks ditaruh di Service.

2. MIDDLEWARE (app/Http/Middleware/)
   Fungsi: Filter HTTP request sebelum sampai ke Controller
   Contoh:
   - GuestMiddleware.php      → Cek user belum login
   - RoleMiddleware.php       → Cek role user (admin/penguji/mahasiswa)
   - HandleInertiaRequests.php → Handle request Inertia.js

3. ROUTES (routes/)
   Fungsi: Mapping URL ke Controller
   Files:
   - web.php     → Route untuk web interface
   - api.php     → Route untuk API endpoints
   - console.php → Route untuk Artisan commands

4. IMPORTS/EXPORTS (app/Imports/, app/Exports/)
   Fungsi: Import/export data dari/ke Excel
   Contoh:
   - MahasiswaImport.php
   - TemplateMahasiswaExport.php

🔗 JENIS-JENIS RELASI DALAM MODEL
================================================================================

1. belongsTo (Many-to-One)
   Contoh: Satu mahasiswa milik satu pengguna
   
   public function pengguna() {
       return $this->belongsTo(Pengguna::class, 'id_pengguna');
   }

2. hasMany (One-to-Many)
   Contoh: Satu mahasiswa punya banyak enrollment
   
   public function enrollment() {
       return $this->hasMany(Enrollment::class, 'id_mahasiswa');
   }

3. belongsToMany (Many-to-Many)
   Contoh: Banyak mahasiswa terdaftar di banyak OSCE
   (Menggunakan pivot table: enrollment_osce)

4. hasOne (One-to-One)
   Contoh: Satu pengguna punya satu profile

✅ KEUNTUNGAN MENGGUNAKAN MVC
================================================================================

1. Separation of Concerns
   → Setiap komponen punya tanggung jawab yang jelas
   
2. Mudah Maintenance
   → Perubahan di satu layer tidak mempengaruhi layer lain
   
3. Reusable Code
   → Model dan Service bisa dipakai ulang di berbagai Controller
   
4. Parallel Development
   → Frontend (View) dan Backend (Model/Controller) bisa dikerjakan bersamaan
   
5. Testable
   → Setiap layer bisa ditest secara terpisah

6. Scalable
   → Mudah menambah fitur baru tanpa merusak kode existing

🎯 POIN PENTING UNTUK UAS
================================================================================

1. Definisi MVC
   - Model: Data & Database
   - View: User Interface
   - Controller: Penghubung Model & View

2. Lokasi File
   - Model: app/Models/
   - View: resources/js/pages/
   - Controller: app/Http/Controllers/

3. Alur Request-Response
   User → Route → Middleware → Controller → Service → Model → Database
   User ← View ← Inertia ← Controller ← Service ← Model ← Database

4. CRUD Operations
   - CREATE = store() = INSERT
   - READ = index()/show() = SELECT
   - UPDATE = update() = UPDATE
   - DELETE = destroy() = DELETE

5. Relasi Model
   - belongsTo (Many-to-One)
   - hasMany (One-to-Many)
   - belongsToMany (Many-to-Many)

6. Layer Tambahan
   - Services: Business logic
   - Middleware: Request filtering
   - Routes: URL mapping

7. Statistik Projek OSCE
   - 18 Models
   - 41 React Views + 4 Blade Views
   - 30+ Controllers
   - 15+ Services
